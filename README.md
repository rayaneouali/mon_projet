# Suivi équipes MDC

[![Tests](https://github.com/rayaneouali/mon_projet/actions/workflows/ci.yml/badge.svg)](https://github.com/rayaneouali/mon_projet/actions/workflows/ci.yml)

App web (Streamlit + PostgreSQL) qui remplace l'agenda : les chefs d'équipe notent chaque jour
qui est présent, absent (et pourquoi), sur quel dossier, et qui travaille le samedi.

Lancer en local : `cp .env.example .env` (puis remplir), `uv sync`, `uv run streamlit run app/Accueil.py`.
