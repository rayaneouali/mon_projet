# Guide des chefs d'équipe — Suivi des équipes MDC

Une page, 2 minutes par jour. À faire **chaque jour**, de préférence le matin.

## 1. Ouvrir l'app (la première fois)

1. Ouvre le lien que Rayane t'a envoyé (par SMS ou WhatsApp).
2. Si tu vois « Yes, get this app back up! » : appuie dessus et attends 30 secondes.
   L'app s'était juste endormie.
3. Tape le **code d'accès des chefs** (6 chiffres), puis **Entrer**.
4. Choisis **ton équipe** dans le menu « Équipe ».

## 2. Mettre l'app sur l'écran d'accueil (une seule fois)

Fais-le **après** avoir tapé le code et choisi ton équipe : l'icône s'en souviendra,
et tu n'auras plus jamais à retaper le code.

- **iPhone (Safari)** : bouton **Partager** (carré avec une flèche) → **Sur l'écran d'accueil** → **Ajouter**.
- **Android (Chrome)** : menu **⋮** en haut à droite → **Ajouter à l'écran d'accueil**.

Une icône « Suivi équipes MDC » apparaît sur ton téléphone, comme une application.

## 3. La saisie du jour

1. Ouvre l'app : la page **Saisie du jour** s'affiche, à la date d'aujourd'hui, avec ton équipe.
2. **Liste des gars** : tes gars sont déjà dedans.
   - Un gars d'une autre équipe vient t'aider ? Ajoute-le dans la liste (c'est un **renfort**).
   - Un gars n'est pas avec toi ? Retire-le avec la petite croix.
3. **Dossier / chantier** : vérifie le dossier (celui de la dernière fois est proposé).
4. **Qui est là ?** Pour chaque gars : **Présent**, ou **Absent · motif**
   (Malade, Congé, Accident, Injustifié, Autre).
5. Appuie sur **Enregistrer**. Le message « Enregistré : 4 gars ✔ » confirme.

Bon à savoir :
- **Tu t'es trompé ?** Refais la saisie et ré-enregistre : la nouvelle remplace l'ancienne.
- **Un oubli hier ?** Change la date en haut de la page, puis fais la saisie.
- **⚠️ « Déjà noté dans Équipe 2 »** : ce gars a déjà été saisi par un autre chef aujourd'hui.
  Si tu enregistres, il passe dans ton équipe.
- **Pas de dossier ?** L'app te demande de confirmer : c'est normal.

## 4. Les autres pages

Menu en haut de l'écran (sur téléphone : bouton **»** en haut à gauche).

- **Semaine** : qui était où, jour par jour. Les absences sont en rouge.
- **Samedis** : demander à des gars de venir un samedi, et noter leur réponse.

## Un problème ?

- **« Code incorrect »** : vérifie le code auprès de Rayane.
- **« Impossible de joindre la base de données »** : vérifie ta connexion internet, réessaie dans une minute.
- Si ça continue, préviens **Rayane** en disant à quelle heure et sur quelle page.
